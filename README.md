Ecosystem documentation for the Zairenkai repositories of `ZairenkaiPrjctX`. Every status here
names its evidence; nothing claims device support or release readiness without it.

| [roadmap/IMPLEMENTATION_ROADMAP.md](roadmap/IMPLEMENTATION_ROADMAP.md) | Phases, acceptance criteria, session checkpoint |
| [security/THREAT_MODEL.md](security/THREAT_MODEL.md) | Ecosystem threats and controls |

Component documents stay in their repositories; these pages link to them rather than restate
them. `anime-extensions` is a separate product and out of scope.
